# Changelog

All notable changes to Navis Docs are documented in this file. The format is inspired by Keep a Changelog; release tags will align with GitHub Releases over time.

## [0.1.0] — Unreleased

First public open-source milestone for Navis Docs on GitHub — platform for organisational knowledge and SOP management.

### Highlights

- **Organisational knowledge base** — Structure SOPs by organisation, department, team, category, and process
- **Multiple documentation formats** — Rich text, sequential steps, flowcharts, and decision trees
- **AI search** — Plain-language questions grounded in published documentation
- **Role-based access** — Owners, admins, and members scoped per organisation
- **Audit trails** — Accountability for edits and operational reviews
- **Favourites, error reporting, idea pipeline** — Lightweight feedback from practitioners
- **Announcements** — Targeted updates to departments and teams
